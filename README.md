# הפועל ירושלים – אפליקציית האוהדים

אפליקציה שנבנתה מהארטיפקט <https://claude.ai/artifact/X6srLrvwjLyFaqs282DPmN>:
משחקים ותוצאות, טבלאות, סגל, כרטיסים, חנות, מנוי והתראות.

## מבנה

| נתיב | תוכן |
|---|---|
| `www/index.html` | קוד האפליקציה (React + htm), כמו בארטיפקט |
| `www/data.json`, `crests.json`, `photos.json` | נתוני העונה, סמלי קבוצות ותמונות שחקנים |
| `www/vendor/` | React, htm ו-CSS של Tailwind – מקומיים, בלי תלות ב-CDN |
| `www/manifest.webmanifest`, `www/sw.js`, `www/icons/` | הגדרות PWA: התקנה למסך הבית ועבודה בלי אינטרנט |
| `capacitor.config.json` | אריזה כאפליקציית Android / iOS |
| `UPDATE.md` | נוהל רענון `data.json` |

## 1. אפליקציית ווב שמותקנת בטלפון (PWA)

האפליקציה מתפרסמת ב-GitHub Pages: <https://nadavilr.github.io/Hapoel-Jerusalem-Unofficial-Fan-App/>
בכל דחיפה ל-`main` שמשנה את `www/`, ה-workflow שב-`.github/workflows/pages.yml` מעדכן את ענף `gh-pages`, ו-Pages מגיש אותו
(Settings → Pages → Deploy from a branch: `gh-pages` / root).
פותחים את הכתובת בטלפון:
- **אנדרואיד (Chrome):** תפריט ⋮ ← "התקנת אפליקציה".
- **אייפון (Safari):** כפתור השיתוף ← "הוספה למסך הבית".

האפליקציה נפתחת במסך מלא עם האייקון של הקבוצה, ואחרי הפתיחה הראשונה עובדת גם בלי אינטרנט
(`data.json` נטען מהרשת כשיש חיבור, ואם אין – מהעותק האחרון).

בדיקה מקומית: `npm run serve` ואז <http://localhost:8080>.

### מסך הבית
כרטיס המשחק הוא קרוסלה שמחליקים בה ימינה ושמאלה (עם נקודות מתחת). היא נפתחת על המשחק הבא (רקע אדום, ספירה לאחור ותזכורת).
מימין נמצא המשחק הקודם, עם תוצאה, ניצחון או הפסד והפרש. משמאל נמצא המשחק שאחריו, עם ספירה לאחור משלו.
שני הכרטיסים האלה מוצגים בצבעי מצב בהיר או כהה של המכשיר.
בכרטיס המשחק הקודם יש כפתור "לתקציר המשחק". בעמוד של כל משחק שהסתיים, סרטון התקציר מוטמע מעל לשוניות הסטטיסטיקה ומתנגן בתוך העמוד.
התקציר נלקח מיוטיוב מהערוץ הרשמי של המפעל (EuroCup, מנהלת ליגת העל) או של הפועל ירושלים, לפי השדה `hl` ב-`data.json`.
אם עוד לא הוזן תקציר, מופיע במקום הסרטון כפתור שפותח חיפוש של תקציר המשחק ביוטיוב.
במעברים בין מסכים, בכרטיסים, בחלונות ובכפתורים יש אנימציות קצרות. הן מתבטלות אם במכשיר מופעלת ההגדרה "הפחתת תנועה".
התאריך מוצג בפורמט "יום ראשון · 08.11.2026 · 20:15".

## 2. אפליקציית אנדרואיד (APK)

בכל דחיפה ל-`main`, ה-workflow שב-`.github/workflows/android.yml` בונה את האפליקציה ומפרסם אותה כ-release לפי מספר הגרסה.
הגרסה האחרונה תמיד כאן: <https://github.com/NadavILR/Hapoel-Jerusalem-Unofficial-Fan-App/releases/latest>
מורידים מהטלפון את `hapoel-jerusalem-vX.X.X.apk`, פותחים ומתקינים מעל הגרסה הקיימת.

באפליקציית האנדרואיד:
- אתר הכרטיסים נפתח כמסך של האפליקציה (`TicketsPlugin.java`), וסרגל הניווט התחתון נשאר גלוי מתחתיו.
- קישורים לאתרים חיצוניים נפתחים בחלון מעל האפליקציה (`MainActivity.java`) עם כפתור "חזור" בצד ימין למעלה,
  שמחזיר למסך שממנו יצאו. כפתור "חזור" של המכשיר חוזר קודם אחורה בתוך האתר, ובדף הראשון שלו סוגר אותו.
- כפתור "חזור" של המכשיר: בכרטיסים, בחנות ובמנוי ← הדף הקודם באתר, ומהדף הראשון ← מסך הבית; עמוד משחק או שחקן ← המסך שממנו הגיעו ← המסך הראשי של הלשונית ← מסך הבית; במסך הבית יוצאים מהאפליקציה.
- ההתראות עוברות דרך מערכת ההתראות של הטלפון, ותזכורות למשחקים מגיעות גם כשהאפליקציה סגורה.

בנייה מקומית: `npm install`, `npx cap sync android`, ואז `cd android && ./gradlew assembleRelease` (צריך Android SDK ו-JDK 17).

### חתימה
כל ה-APK-ים נחתמים באותו מפתח (`android/keystore/hpj-release.jks`), כדי שכל גרסה תותקן כעדכון מעל הקודמת.
המפתח נמצא בריפו הציבורי לבקשת בעל הריפו, ולכן כל אחד יכול לחתום בו: מתקינים רק APK שהורדו מעמוד ה-Releases של הריפו הזה.

### עדכונים מתוך האפליקציה
אפליקציית האנדרואיד בודקת בכל פתיחה (ובכל חזרה אליה) את הגרסה האחרונה ב-GitHub Releases. כשיש גרסה חדשה מופיעה התראה במרכז ההתראות ומסך "עדכון חדש זמין"
שחוסם את השימוש עד העדכון; "עדכן עכשיו" מוריד את ה-APK ופותח את מסך ההתקנה (`UpdaterPlugin.java`). בפעם הראשונה אנדרואיד מבקש לאשר התקנה מהאפליקציה.
גם כשהאפליקציה סגורה, בדיקה ברקע (`UpdateCheckWorker.java`, בערך כל 6 שעות כשיש אינטרנט) שולחת התראה "עדכון חדש זמין" פעם אחת לכל גרסה; לחיצה עליה פותחת את האפליקציה במסך העדכון.
בכפתור ההגדרות (גלגל השיניים, במסכי הבית, משחקים, טבלאות וסגל) אפשר להפעיל ולבטל התראות ולחפש עדכונים ידנית.

### רענון נתונים
"רענן נתונים עכשיו" (וגם כל פתיחה של האפליקציה) טוען את קובץ הנתונים העדכני מהאתר, ומעדכן ברגע הלחיצה מהמקורות הרשמיים:
תוצאות ומועדי משחקי היורוקאפ וטבלת היורוקאפ (EuroLeague, באנדרואיד ובדפדפן), ותוצאות ומועדי משחקי הליגה והגביע וטבלת ליגת ווינר
(basket.co.il, באנדרואיד בלבד – האתר חוסם גישה מדפדפנים). סגל וסטטיסטיקות שחקנים מגיעים מקובץ הנתונים.

### משחק בלייב
מ-10 דקות לפני שריקת הפתיחה ועד הסיום האפליקציה בודקת ב-365scores (webws.365scores.com) כל 20 שניות. מרגע שהמשחק מתחיל, כרטיס המשחק במסך הבית
מציג תוצאה, רבע, שעון ותוצאות לפי רבעים, ועמוד המשחק מציג בלייב את הסטטיסטיקות המלאות – לפי רבעים, קבוצתיות ואישיות – באותן לשוניות שמופיעות
אחרי המשחק (`gs365` ממיר את נתוני 365scores למבנה של האפליקציה). בסיום התוצאה והסטטיסטיקות נשמרות, נשלחת התראה והכרטיס חוזר לספירה לאחור למשחק הבא.

### מהלך המשחק (Play by Play) בלייב
בזמן משחק נוספת לעמוד המשחק לשונית "מהלך המשחק": כל פעולה בעברית עם רבע, שעון ותוצאה אחרי כל סל, החדשות למעלה.
יורוקאפ: live.euroleague.net לפי מספר המשחק (באנדרואיד ובדפדפן). ליגת ווינר וגביע ווינר: basket.co.il/livestats – מספר המשחק ב-livestats
שונה ממספר המשחק באתר האיגוד, ולכן האפליקציה מוצאת אותו ברשימת המשחקים הנוכחיים (`/livestats/data/games.json`) לפי שם הקבוצה ושעת הפתיחה,
וטוענת את `/livestats/data/game-<מספר>.json` (באנדרואיד בלבד – האתר חוסם דפדפנים).

## מספר גרסה

מספר הגרסה נמצא בקובץ `VERSION` ומוצג בתחתית האפליקציה, בשם קובץ ה-APK ובמידע על האפליקציה באנדרואיד.
בכל תיקון מעלים גרסה: `node scripts/bump-version.js`. עד 1.1.8 הפורמט היה X.Y.Z, ומאז הוא 1.XX: 1.1.8 ← 1.19 ← 1.20 ← 1.21 …
תגית ה-release ב-GitHub נשארת בפורמט X.Y.Z (גרסה 1.19 מתפרסמת בתגית `v1.19.0`), כדי שגם גרסאות ישנות של האפליקציה יזהו את העדכון.
הסקריפט מעדכן גם את `www/version.js` ואת שם המטמון ב-`www/sw.js`, כך שהטלפונים מקבלים את הגרסה החדשה.

## עדכון נתונים ושינוי עיצוב
