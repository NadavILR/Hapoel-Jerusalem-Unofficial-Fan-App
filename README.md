# הפועל ירושלים – אפליקציית האוהדים (לא רשמית)

אפליקציה בעברית לאוהדי הפועל ירושלים בכדורסל. במקום אחד יש בה:
- **משחקים ותוצאות בלייב**, עם סטטיסטיקות, מהלך המשחק ותקצירי וידאו;
- **טבלאות של כל המפעלים**;
- **הסגל** עם סטטיסטיקה לכל שחקן;
- **כרטיסים, חנות ומנוי**;
- **התראות לטלפון**.

האפליקציה עובדת באנדרואיד, ובכל טלפון אחר כאפליקציית ווב שמתקינים למסך הבית.

## מה יש באפליקציה

### מסך הבית
- **קרוסלת משחקים:** מחליקים בין המשחק הקודם (מימין), המשחק הבא (במרכז) והמשחק שאחריו (משמאל).
- **המשחק הבא:**
  - הסמלים של שתי הקבוצות, תאריך בפורמט "יום ראשון · 08.11.2026 · 20:15" ואולם;
  - ספירה לאחור בימים, שעות, דקות ושניות;
  - כפתור תזכורת וכפתור לעמוד המשחק.
- **המשחק הקודם:** התוצאה, ניצחון או הפסד וההפרש, וכפתור שפותח את **תקציר המשחק** בחלון קופץ בתוך האפליקציה.
- **משחק בלייב:** מרגע שריקת הפתיחה הכרטיס מציג את התוצאה, הרבע, השעון והתוצאות לפי רבעים. הנתונים מתעדכנים כל 20 שניות.
- **המיקום בטבלאות:** המיקום בליגת ווינר סל וביורוקאפ, עם מאזן הניצחונות וההפסדים.
- **חדשות המועדון:** כותרות אחרונות עם קישור לכתבה.
- **רענון נתונים:** "רענן נתונים עכשיו" מעדכן תוצאות, מועדים וטבלאות ישירות מהמקורות הרשמיים.

### משחקים ותוצאות
- כל משחקי העונה, עם לשוניות של המשחקים הבאים והמשחקים הקודמים.
- סינון לפי מפעל: ליגת ווינר סל, יורוקאפ, גביע המדינה, גביע ווינר סל ומשחקי הכנה.
- תזכורת לכל משחק, ובמשחקי בית גם כפתור לכרטיסים.

### עמוד משחק
- התוצאה, הסמלים, האולם והתאריך.
- **תקציר וידאו** שמתנגן בתוך העמוד, מהערוץ הרשמי של המפעל או של הפועל ירושלים.
- **סטטיסטיקות:**
  - תוצאה לפי רבעים;
  - סטטיסטיקה קבוצתית (קליעה, ריבאונדים, אסיסטים, חטיפות, איבודים ועוד);
  - סטטיסטיקה אישית לכל שחקן בשתי הקבוצות.
- **בזמן המשחק:** כל הסטטיסטיקות מתעדכנות בלייב, ונוספת לשונית **"מהלך המשחק"** – כל פעולה בעברית, עם רבע, שעון ותוצאה מתעדכנת.
- קישורים לעמוד המשחק ב-365scores ובאתר הרשמי של המפעל.

### טבלאות
- ליגת ווינר סל, בתי היורוקאפ, בתי גביע ווינר סל וגביע המדינה.
- **סימון צבעוני ליד מספר המקום:**
  - **ליגת ווינר סל:** פלייאוף במקומות 1–6 (ירוק), פליי-אין במקומות 7–10 (סגול), בית תחתון במקומות 11–14 (אדום).
  - **יורוקאפ:** פלייאוף במקומות 1–4 (ירוק).
  - **גביע ווינר סל:** רבע גמר (ירוק) ופליי-אין (סגול).
- בראקטים של שלבי הנוקאאוט והפלייאוף.

### סגל
- תמונת הקבוצה וכרטיס לכל שחקן, עם סינון לגארדים, פורוורדים וסנטרים.
- צוות האימון ובעלי התפקידים.
- **עמוד שחקן:**
  - מספר, עמדה, גובה, אזרחות, תאריך לידה וגיל;
  - סטטיסטיקה אישית לפי מפעל (ממוצע למשחק או סה״כ);
  - טבלת "משחק אחר משחק".

### כרטיסים, חנות ומנוי
- בתפריט "עוד" שבסרגל התחתון.
- אתר הכרטיסים, החנות הרשמית ואזור המנויים נפתחים בתוך האפליקציה, וסרגל הניווט נשאר גלוי.

### התראות
- התראות למכשיר:
  - תזכורות למשחקים;
  - תחילת משחק וסיומו, עם התוצאה.
- תזכורות מגיעות גם כשהאפליקציה סגורה (באנדרואיד).
- **מרכז ההתראות:**
  - מחליקים התראה הצידה כדי למחוק אותה.
  - "סמן הכל כנקרא" מנקה את כל ההתראות.
- **הגדרות** (גלגל השיניים): הפעלה וכיבוי של התראות, לפי סוג ולפי מפעל.

### עדכונים (אנדרואיד)
- בכל פתיחה של האפליקציה ובכל חזרה אליה היא בודקת אם יש גרסה חדשה. אם יש, מסך העדכון מופיע מיד, עם מה חדש בגרסה.
- "עדכן עכשיו" מוריד את הגרסה ופותח את מסך ההתקנה בלחיצה אחת, וההתקנה היא מעל הגרסה הקיימת.
- "חפש עדכונים" בהגדרות בודק ידנית.

### עיצוב ונוחות
- **צבעי המועדון:** אדום ‎#D21919 ושחור, עם מצב בהיר ומצב כהה לפי הגדרות הטלפון.
- **גופן:** Noto Sans Hebrew.
- **עיצוב זכוכית חלבית:** הכותרת, סרגל הניווט, התפריטים והחלונות שקופים ומטשטשים את התוכן שמאחוריהם, וברקע מסך הבית מוצגת תמונת הקבוצה.
- **אנימציות קצרות:** הן מתבטלות כשבטלפון מופעלת ההגדרה "הפחתת תנועה".
- **כפתור "חזור" של המכשיר** עובר בין מסכי האפליקציה, ובאתרים שבתוכה הוא חוזר דף אחורה.
- **מכשירים:** עובד גם בטאבלטים, ובלי זום.
- **בלי אינטרנט:** אחרי הפתיחה הראשונה האפליקציה עובדת גם בלי חיבור, עם הנתונים האחרונים.

## למפתחים

### מבנה

| נתיב | תוכן |
|---|---|
| `www/index.html` | קוד האפליקציה (React + htm) |
| `www/data.json`, `crests.json`, `photos.json` | נתוני העונה, סמלי קבוצות ותמונות שחקנים |
| `www/vendor/` | React, htm, ה-CSS של Tailwind והגופן Noto Sans Hebrew (Google Fonts, רישיון SIL OFL 1.1), שמורים מקומית |
| `www/manifest.webmanifest`, `www/sw.js`, `www/icons/` | PWA: התקנה למסך הבית ועבודה בלי אינטרנט |
| `android/` | אפליקציית האנדרואיד (Capacitor), כולל `TicketsPlugin` ו-`UpdaterPlugin` |
| `CHANGELOG.md` | מה חדש בכל גרסה (הופך לתיאור הגרסה ב-GitHub Releases) |
| `UPDATE.md` | נוהל רענון `data.json` |

### פרסום
- **אפליקציית ווב:** בכל דחיפה ל-`main` שמשנה את `www/`, ה-workflow `pages.yml` מעדכן את ענף `gh-pages`, ו-GitHub Pages מגיש אותו.
- **אנדרואיד:**
  - ה-workflow `android.yml` בונה APK חתום ומפרסם release לפי מספר הגרסה.
  - כל ה-APK-ים נחתמים באותו מפתח, כך שכל גרסה מותקנת כעדכון. המפתח והסיסמאות שלו שמורים בסודות של המאגר ב-GitHub (`HPJ_KEYSTORE_BASE64`, `HPJ_STORE_PASSWORD`, `HPJ_KEY_ALIAS`, `HPJ_KEY_PASSWORD`) ולא בקוד.
  - המפתח נמצא בריפו הציבורי לבקשת בעל הריפו, ולכן כדאי להתקין רק APK מעמוד ה-Releases של הריפו הזה.
- **בנייה מקומית:** `npm install`, `npx cap sync android`, ואז `cd android && ./gradlew assembleRelease` (צריך Android SDK ו-JDK 17).
- **בדיקה מקומית של הווב:** `npm run serve`, ואז <http://localhost:8080>.

### גרסאות ו"מה חדש"
1. בכל שינוי מריצים `node scripts/bump-version.js`.
   - הסקריפט מעלה את הגרסה (1.30 ← 1.31 ← …) ומעדכן את `VERSION`, את `www/version.js` ואת המטמון ב-`www/sw.js`.
   - הוא מוסיף ל-`CHANGELOG.md` כותרת לגרסה החדשה.
2. כותבים מתחת לכותרת מה חדש בגרסה, ברשימת נקודות קצרה בעברית.
3. ה-release של הגרסה מתפרסם עם הטקסט הזה (`scripts/release-notes.js`).
4. ה-workflow `release-notes.yml` מסנכרן את התיאור של כל ה-releases הקיימים בכל שינוי של `CHANGELOG.md`.

**תגיות:** תגית ה-release תמיד בפורמט X.Y.Z. גרסה 1.31 מתפרסמת בתגית `v1.31.0`, כדי שגם גרסאות ישנות של האפליקציה יזהו את העדכון.

### מקורות הנתונים בלייב
- **רענון נתונים:**
  - יורוקאפ: תוצאות, מועדים וטבלה מ-EuroLeague.
  - ליגת ווינר והגביעים: מ-basket.co.il (באנדרואיד בלבד, כי האתר חוסם דפדפנים).
- **משחק בלייב:** 365scores, מ-10 דקות לפני שריקת הפתיחה ועד הסיום, כל 20 שניות.
- **מהלך המשחק:**
  - יורוקאפ: live.euroleague.net.
  - ליגת ווינר והגביעים: basket.co.il/livestats. מספר המשחק שם שונה מזה שבאתר האיגוד, ולכן האפליקציה מוצאת אותו לפי שם הקבוצה ושעת הפתיחה.
- **עדכוני גרסה:** ה-API של GitHub. כשהוא חסום, האפליקציה בודקת דרך פיד הגרסאות הציבורי (`releases.atom`).

### עדכון נתונים ועיצוב
- **נתונים:** מחליפים את `www/data.json` לפי `UPDATE.md`, כולל קישורי התקצירים (`hl`).
- **עיצוב:** אם מוסיפים ל-`index.html` מחלקות Tailwind חדשות, מריצים `npm install` ואז `npm run build:css`.
